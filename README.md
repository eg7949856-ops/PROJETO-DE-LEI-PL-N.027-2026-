# PROJETO DE LEI — ENERGIA SOLAR

### Alto Paraíso — 2026

Apresentação interativa sobre o Projeto de Lei
PL n.º 027/2026.

O projeto propõe incentivar a utilização de energia
solar em prédios públicos e residências.

## COMO EXECUTAR

1. Abra o Visual Studio Code.
2. Clique em Arquivo.
3. Selecione Abrir Pasta.
4. Escolha a pasta PROJETO_ENERGIA_SOLAR.
5. Abra o arquivo index.html.
6. Clique com o botão direito.
7. Selecione Open with Live Server.

Também é possível abrir o index.html diretamente
no navegador.
